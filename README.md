# Piyumal — Cloud & DevOps Portfolio

Next.js 15 + React + TypeScript starter with a cyberpunk cloud/DevOps visual style.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Check
```bash
npm run typecheck
npm run build
```

## Add content
Edit `data/portfolio.ts`. Add objects to `projects`, `certifications`, or `creativeWorks`; the corresponding section maps the arrays into reusable card components. Only one sample entry exists in each array. Replace sample details and contact links with your own verified information before publishing.

No deployment or cloud infrastructure setup is included.
